System Architecture
1
Pose Reader
MediaPipe Holistic · GPU
Extracts 75 landmarks per frame (21 left hand + 21 right hand + 33 upper body pose), producing 225 values per frame. Real-time pose estimation without raw pixel processing.
2
Sign Reader
Bi-LSTM / Siformer · GPU
Receives a normalized 64-frame × 225-value sequence and outputs a predicted sign label with confidence score. Controlled comparison between baseline and advanced architecture.
3
Translator
Facebook NLLB-200 (600M) · CPU
Translates English sign labels to Filipino (tgl_Latn). Hand-curated override dictionary covers all 105 FSL-105 labels; NLLB-200 serves as fallback for unseen text.
4
Speaker
Qwen3-TTS 0.6B · GPU
Neural text-to-speech at 24kHz. Converts recognized and translated text into spoken audio. Fits within 8GB VRAM alongside other pipeline components.

Data Preprocessing
Landmark Extraction

Each video clip (~120 frames at 30fps) processed through MediaPipe Holistic. Outputs 75 landmarks per frame (21 left hand + 21 right hand + 33 upper body). Face landmarks (478 points) excluded to reduce noise. Missing hands forward-filled from last detection with confidence mask.

Normalization
  • Re-centering: Mid-chest point subtracted from all landmarks (torso-relative)
  • Shoulder-width scaling: All coordinates divided by shoulder distance
  • Temporal resampling: All clips resampled to 64 frames via linear interpolation
Data Augmentation

Applied on-the-fly during training to compensate for small dataset (~20 clips/sign):
